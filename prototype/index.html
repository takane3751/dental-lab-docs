特に見ていただきたい点

いただいたご回答のうち、設計の根幹に関わった7点を画面で確認できるようにしています。

規模小規模・中規模・大型を切り替える 技工所側 → ヘッダーの「規模」。既定は小規模ラボです。 切り替えると進行中件数・技工士数・取引医院数が変わります。 ★小規模・中規模の件数はまだ伺えていないため仮の数字です。実際の目安をお聞かせください。
工程大工程13 ＋ 仕上げの細分工程 技工所側 → 設定 → 細分工程。いただいた9パターン（7〜16手順）が入っています。 ↑↓で順番を入れ替え、手順の追加・削除ができます。 「定められるのは大まかな形だけ」というお話をそのまま形にしました。 ★細分工程には RFID の読み取りを置いていません（1手順ごとに読ませると現場が止まるため）。
RFID完了棚と「前の工程の完了棚」 工程端末 → 帯の並びは 作業中 → 待機 → 前の工程 → 完了。 ★「すぐ来る（前の工程の完了棚）」と「まだ来ない（作業中・待機中）」を分けて出しています。 デモ操作の「作業中の台 → 完了棚に移す」で実作業時間が確定します。
納期アポイントベースの納期 医院側 → 新規依頼。保険1週間・自費2週間が起点で、本数が増えても日数は変わりません。 次回ご来院日を入れるとその前日にお届けする日程になります（前もって作りすぎない）。 ご来院日が最短より前だと「◯日間に合いません」と出て特急をご案内します。
特急20 / 50 / 100 / 150% 「特急料金で対応」を押すと4段階が並びます。通常との差額を必ず出しています。 上限は4日短縮、義歯は対象外です（来院のたびに医院を経由するため縮められません）。
再製作責任の所在の申告（必須） 医院側 → 納品完了の案件 → 「不具合を報告」。 前回の指示書が自動で添付され、外せません。 責任の所在を選ばないと送信できません（押すとその項目まで自動でスクロールします）。 「修正」と「再製作」も別のものとして扱っています。
変更仕様変更の料金 技工所側 → 設定 → 仕様変更の料金。文言を編集でき、医院の画面での見え方をその場で確認できます。 医院側では加工後も「仕様の変更を依頼する」が出ます（お断りしません）。 受注時に「変更の可能性あり」を申告すると技工料が発生しません。
評価難易度★と面談シート 難易度は全画面で★表示にしました（数値は出していません）。 技工所側 → 作業時間 → 月次グラフと面談シート。 面談シートは点数・順位・他の方との比較を載せていません。紙で渡す1枚です。
発送発送日を第一の日付に 技工所側 → 案件一覧・案件ボード・指示書。発送日が主、納期（医院着）は「◯/◯(◯)着」で併記です。 発送予定タブは本日・明日・明後日を日ごとに区切り、スマホの縦画面で成立します。
RFID誤配置アラートは確認では消えません 工程端末 → デモ操作の「別工程のトレイを置く」で発報します。 「確認」を押すと点滅は止まりますが、帯は残ります。 「戻した」を押して現物が正しい場所に戻ったときだけ消えます。 「通信を切断」でオフライン時の挙動も確認できます。
端末管理者だけ発送予定日を変えられます 工程端末 → ヘッダーの「管理者操作」（デモのコードは 1234）。 入れている間だけ各明細に「発送日を変更」が出ます。 変えられるのは発送予定日だけで、仕様・承認・検収は端末からは行えません。 誰が・いつ・何を・なぜ変えたかを記録に残します。
設定RFIDを使わない運用 技工所側 → 設定 → RFID のスイッチをオフにすると、トレイ・エリア端末の設定が使用不可になり、 案件一覧のトレイ列も消えます。RFIDなしでも成立することを確認できます。
指示書紙とデジタルの両対応 技工所側 → 設定 → 指示書。A6/A5/A4 の印刷プレビューが出ます。 ★発送日を大きく出し、医院着を下に小さく入れています。同じレイアウトを電子ペーパーにも配信します。
表示設定技工所・医院ごとのロゴとテーマカラー 技工所側 → 設定 → 表示設定／医院側 → 設定 → 表示設定。色を変えると画面全体に反映されます。 運営側は取り違え防止のため紫で固定です。
CSV導入時の一括登録に対応 医院マスタ・単価表・技工物×材料・細分工程・請求・トレイなどを CSV で出力／取込できます。 取込は必ずプレビューを挟み、いきなり反映しません。
取引取引開始はどちらからでも申請できます 医院側 → 取引先技工所 → 「技工所に取引を申請する」（デモのコードは LAB-0207）。 ★承認は医院管理者に限りません。承認権限をお持ちの方が承認できます。 技工所コードは完全一致のみです（一覧を出さないため）。
運営サービス利用料とキャンセル 運営側 → サービス利用料。算定の起点は「医院への請求確定」です。 医院が未入金でも利用料は立ち、技工所が請求を取り下げた案件だけが対象外になります。
