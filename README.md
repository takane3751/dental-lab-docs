# 歯科技工物 管理・受発注システム — 操作デモ

歯科医院と歯科技工所のあいだの技工物の受発注をデジタル化するシステムの、**操作デモ**です。

**https://takane3751.github.io/dental-lab-docs/**

| 画面 | 内容 |
|---|---|
| `prototype/clinic.html` | 医院側 — 依頼の作成・承認・検収 |
| `prototype/lab.html` | 技工所側 — 案件ボード・工程・請求・採算 |
| `prototype/station.html` | 工程エリア端末 — 現場の閲覧専用画面 |
| `prototype/staff.html` | スタッフ端末（スマホ）— 指示書のQRを読んで着手・完了を記録 |
| `prototype/admin.html` | 運営管理コンソール — テナント・料金・請求 |

## 注意

- **データはすべて架空です。** 実在の医院・技工所・患者とは関係ありません。
- 外部ライブラリを使っていません。`prototype/` の5ファイルと `shared.js` だけで動きます。
- **このリポジトリは操作デモだけを公開しています。** 要件定義書・基本設計書・フロー図・
  議事録などの設計資料は含みません。ご入用の際は個別にお送りします。
